# Texture credits

All texture sets below are **CC0 1.0 (public domain)** — free to use, redistribute,
and modify, no attribution required. Sourced from **ambientCG** (https://ambientcg.com),
which releases all its material scans under CC0.

Each set was downloaded as the 1K-JPG package; only the maps actually used in the
scene were kept (Color, NormalGL, Roughness, AmbientOcclusion), and the JPEGs were
re-compressed (quality ~60) to keep the bundle lean. The `.blend/.usdc/.mtlx/.tres`
project files and the DX-normal/displacement maps were discarded.

| Folder        | Source set        | ambientCG page                                  | Used on (scene surface)                          | Maps kept                       |
|---------------|-------------------|-------------------------------------------------|--------------------------------------------------|---------------------------------|
| `concrete/`   | Concrete032 (1K)  | https://ambientcg.com/view?id=Concrete032       | Tower body facade + glazed ground-floor plinth   | color, normal (GL), roughness, ao |
